Mathematical Principles & Equations

RMS vs Peak Values

Vrms = V0 / √2  |  Irms = I0 / √2

Effective values delivering equivalent DC heating power in resistive loads.

Instantaneous Equations

v(t) = V0 sin(ωt)  |  i(t) = I0 sin(ωt - ϕ)

Exact current and voltage values at any given instant in time.

Total Impedance (Z)

Z = √( R² + (XL - XC)² )

Total opposition to AC current flow combining resistive and reactive parts.

Active Power

Pavg = Vrms x Irms x cos(ϕ)

Real power consumed by resistive components in watts (W).
